# Commercial Discovery Skill - 77 Studio

Usa este procedimiento cuando un usuario muestre interés comercial pero tenga una idea difusa de sus necesidades o esté evaluando opciones de agencia/partner.

## Procedimiento de Descubrimiento

1. **Diagnosticar el Estado Actual:**
   - ¿Qué tipo de negocio tiene? (B2B, B2C, Startup, Empresa de servicios).
   - ¿Cuál es su principal cuello de botella hoy? (Pocos leads, web lenta/anticuada, procesos manuales, falta de producto digital).

2. **Demostrar Comprensión:**
   - Valida su problema sin tecnicismos excesivos.
   - Explica brevemente cómo 77 Studio aborda esa situación (unificando diseño, código y marketing en un solo equipo).

3. **Cierre hacia Diagnóstico Gratuito:**
   - Proponer la **llamada de diagnóstico de 15 minutos** con el equipo fundador.
   - Enlace directo a WhatsApp para coordinar horario.
