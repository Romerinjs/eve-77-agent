# Technical Scoping Skill - 77 Studio

Usa este procedimiento cuando un usuario pregunte por detalles técnicos de desarrollo, tiempos de entrega, arquitecturas o viabilidad de una plataforma digital.

## Procedimiento de Alcance Técnico

1. **Selección del Stack Óptimo:**
   - **Sitio Web Corporativo / Landing Page:** Recomendar **Astro 5.x** (Arquitectura de Islas, Zero JS, carga < 1s, SEO optimizado).
   - **Plataforma Web Interactiva / Dashboard / SaaS:** Recomendar **Next.js / React** con TypeScript y Tailwind CSS.

2. **Tiempos de Entrega Estándar:**
   - *Landing Pages:* 1 a 2 semanas.
   - *Sitios Corporativos completos:* 2 a 4 semanas.
   - *MVPs / Plataformas SaaS:* 3 a 6 semanas (metodología Product Studio en sprints).

3. **Garantías de Calidad:**
   - Enfoque *Mobile-First*.
   - Integración con analítica (GA4 / Meta CAPI) y formularios con CRM/WhatsApp.
